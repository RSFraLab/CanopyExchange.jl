Quantities & Layer Geometries

Scalar exchange records in CanopyExchange separate conserved chemical/energetic payloads (ExchangeRates) from their spatial integration denominators (LeafFlux, StemFlux, FaceFlux, VolumeSource, and MoistAirTendencies) and finite-volume layer descriptors (LayerGeometry and PlantLayerGeometry).

All wrapper types support eltype, convert and promote_rule across compatible continuous scalars (Float64 with ForwardDiff.Dual{Tag,Float64,N}), ==, isequal, hash, broadcastable, and measure-safe linear algebra (+, -, unary -, scalar *, scalar /). Flux and tendency records also define zero.

Optional Molecular Oxygen

CanopyExchange.OxygenContent — Type
OxygenContent{FT<:Real}

Represent optional transported molecular oxygen in scalar exchange records.

Absence (NoOxygen) is distinct from a computed zero transfer (OxygenTransfer). See oxygen_value.

CanopyExchange.NoOxygen — Type
NoOxygen{FT}()
NoOxygen(::Type{FT})

Mark oxygen transfer as uncomputed for continuous scalar type FT.

oxygen_value returns nothing on NoOxygen instances.

Examples

julia> oxygen_value(NoOxygen(Float64)) === nothing
true
CanopyExchange.OxygenTransfer — Type
OxygenTransfer(value)
OxygenTransfer{FT}(value)

Wrap signed molecular oxygen transfer value in mol O₂ per container measure and second.

Examples

julia> oxygen_value(OxygenTransfer(1.25e-5))
1.25e-5
CanopyExchange.oxygen_value — Function
oxygen_value(oxygen::OxygenContent)

Return nothing for NoOxygen or the scalar mol O₂ transfer for OxygenTransfer.

Examples

julia> (oxygen_value(NoOxygen(Float32)), oxygen_value(OxygenTransfer(2.5f-5)))
(nothing, 2.5f-5)

See also NoOxygen, OxygenTransfer.

Conserved Exchange Rates & Validity

CanopyExchange.ExchangeRates — Type
ExchangeRates(energy, water, carbon, oxygen=NoOxygen(FT))
ExchangeRates(; energy, water, carbon, oxygen=nothing)

Bundle conserved transfer rates for energy [J], water [kg H₂O], carbon [mol C], and optional oxygen [mol O₂], each per second and per wrapper spatial measure.

All numeric fields and oxygen share one continuous scalar type FT (or promote cleanly across compatible primal and automatic-differentiation scalars). Passing oxygen=nothing in the keyword constructor selects NoOxygen{FT}(). Carbon exchange represents CO₂ molar transfer (1 mol C per mol CO₂), not biochemical enthalpy of assimilated carbohydrate.

energy represents total energy transfer under a caller-declared thermodynamic convention rather than sensible or latent heat in isolation. Host adapters own conversions between conserved density tendencies and temperature or humidity.

Examples

julia> r = ExchangeRates(120.0, 2.0e-5, -1.0e-5)
ExchangeRates{Float64, NoOxygen{Float64}}(120.0, 2.0e-5, -1.0e-5, NoOxygen{Float64}())

julia> valid_exchange(r)
true

See also LeafFlux, StemFlux, FaceFlux, VolumeSource.

CanopyExchange.valid_exchange — Function
valid_exchange(x) -> Bool

Return true if every computed scalar component of x (including dual partials) is finite.

Accept ExchangeRates, any AbstractExchangeFlux, and MoistAirTendencies. NoOxygen is treated as valid; hosts remain responsible for thermodynamic admissibility and retry policy.

Examples

julia> valid_exchange(LeafFlux(ExchangeRates(100.0, 2.0e-5, -1.0e-5)))
true

julia> valid_exchange(LeafFlux(ExchangeRates(NaN, 2.0e-5, -1.0e-5)))
false

See also CanopyExchange.finite_scalar, ExchangeRates, MoistAirTendencies.

Measure-Tagged Flux & Source Wrappers

CanopyExchange.AbstractExchangeFlux — Type
AbstractExchangeFlux{FT<:Real,O<:OxygenContent{FT}}

Supertype for measure-tagged exchange wrappers (LeafFlux, StemFlux, FaceFlux, and VolumeSource).

Distinct concrete subtypes prevent accidental addition or argument substitution across one-sided leaf area, one-sided stem area, horizontal ground area, and bulk canopy volume.

CanopyExchange.LeafFlux — Type
LeafFlux(rates::ExchangeRates)

Wrap rates as a flux per m² one-sided leaf area per second, positive from leaf into air.

Examples

julia> f = LeafFlux(ExchangeRates(100.0, 3.0e-5, -1.2e-5));

julia> f.rates.carbon
-1.2e-5

See also sensible_water_flux, leaf_air_sources, StemFlux.

CanopyExchange.StemFlux — Type
StemFlux(rates::ExchangeRates)

Wrap rates as a flux per m² one-sided woody/stem area per second, positive from stem into air.

Keeping StemFlux distinct from LeafFlux prevents swapping leaf and stem arguments in plant_air_sources or adding fluxes across unequal leaf (LAD) and stem (SAD) area denominators.

Examples

julia> s = StemFlux(ExchangeRates(25.0, 0.0, 0.0));

julia> s.rates.energy
25.0

See also sensible_stem_flux, plant_air_sources, LeafFlux.

CanopyExchange.FaceFlux — Type
FaceFlux(rates::ExchangeRates)

Wrap rates as a flux per m² horizontal ground area per second, positive upward.

Examples

julia> ff = FaceFlux(ExchangeRates(180.0, 5.0e-5, -1.5e-5));

julia> ff.rates.energy
180.0

See also surface_static_energy_flux, layer_tendency, steady_top_flux.

CanopyExchange.VolumeSource — Type
VolumeSource(rates::ExchangeRates)

Wrap rates as a source per m³ bulk canopy volume per second, positive into the named reservoir.

Examples

julia> vs = VolumeSource(ExchangeRates(50.0, 1.0e-5, -0.5e-5));

julia> vs.rates.water
1.0e-5

See also leaf_air_sources, plant_air_sources, moist_air_tendencies.

CanopyExchange.MoistAirTendencies — Type
MoistAirTendencies(rho_total, rho_water, rho_energy, carbon, oxygen=NoOxygen(FT))
MoistAirTendencies(; rho_total, rho_water, rho_energy, carbon, oxygen=nothing)

Store conserved atmospheric gas-volume source tendencies per m³ gas volume per second.

Fields map directly to conserved moist-air prognostic budgets (ClimaAtmos / porous-canopy hosts with conserved dry-air mass S_ρd = 0):

  • rho_total: total moist-air mass source [kg m⁻³ gas s⁻¹] (== rho_water when S_ρd = 0),
  • rho_water: total water mass source [kg H₂O m⁻³ gas s⁻¹],
  • rho_energy: total energy density source [J m⁻³ gas s⁻¹] in the host's datum,
  • carbon: passive molar CO₂ source [mol C m⁻³ gas s⁻¹],
  • oxygen: optional molar O₂ source [mol O₂ m⁻³ gas s⁻¹] (nothing keyword selects NoOxygen{FT}()).

Momentum, canopy drag, and subgrid turbulent kinetic energy are excluded.

Examples

julia> m = MoistAirTendencies(; rho_total=4.0e-5, rho_water=4.0e-5, rho_energy=150.0, carbon=-1.0e-5);

julia> (m.rho_total, m.rho_energy)
(4.0e-5, 150.0)

See also moist_air_tendencies, VolumeSource.

Finite-Volume Layer Geometries

CanopyExchange.AbstractLayerGeometry — Type
AbstractLayerGeometry{FT<:Real}

Supertype for canopy finite-volume layer geometry descriptors (LayerGeometry and PlantLayerGeometry).

CanopyExchange.LayerGeometry — Type
LayerGeometry(thickness, leaf_area_density)

Store finite positive layer thickness [m] and finite nonnegative one-sided leaf_area_density [m² leaf m⁻³ bulk canopy].

Bulk volume equals horizontal ground footprint multiplied by thickness with no implicit air-porosity factor. Throw ArgumentError if thickness ≤ 0, leaf_area_density < 0, or any scalar component (including dual partials) is nonfinite.

Examples

julia> g = LayerGeometry(1.5, 0.8)
LayerGeometry{Float64}(1.5, 0.8)
CanopyExchange.PlantLayerGeometry — Type
PlantLayerGeometry(thickness, leaf_area_density, stem_area_density=zero(FT))

Store finite positive thickness [m] with nonnegative one-sided leaf_area_density [m² leaf m⁻³] and stem_area_density [m² stem m⁻³] (PAI = LAI + SAI as in ClimaLand).

Throw ArgumentError if thickness ≤ 0, either area density is negative, or any scalar component (including dual partials) is nonfinite.

Examples

julia> g = PlantLayerGeometry(2.0, 1.2, 0.3)
PlantLayerGeometry{Float64}(2.0, 1.2, 0.3)

julia> plant_area_density(g)
1.5
