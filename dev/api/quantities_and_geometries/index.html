Records, Measures & Layer Geometries

Exchange rates (ExchangeRates: energy, water and an open set of passive molar tracers) are separated from the spatial measure they are expressed per (Exchange with a Measure) and from the finite-volume layer descriptors. Gas-volume host tendencies are MoistAirTendencies.

All records are immutable and isbits for plain floats, act as scalars in broadcasts, compare by value and derivative components (-0.0 == 0.0, NaN != NaN; isequal and hash consistent), and support componentwise +, -, unary -, scalar * and / and zero. They are not collections (no map, iteration or length). A vector of a plain and a dual-valued record promotes to a concrete dual-valued element type.

Rates and tracers

CanopyExchange.ExchangeRates — Type
ExchangeRates(energy, water, tracers::NamedTuple = (;))
ExchangeRates(; energy, water, tracers = (;))

Conserved transfer rates, each per second and per measure of the enclosing Exchange (one-sided leaf or stem area, ground area or bulk volume):

  • energy [J s⁻¹ per measure]: total energy transfer under one caller-declared thermodynamic datum, not sensible or latent heat in isolation. It includes the enthalpy carried by transported water vapour (see sensible_water_flux); do not add a second latent-heat term when coupling to a conserved air energy budget.
  • water [kg H₂O s⁻¹ per measure]: total water mass transfer.
  • tracers [mol s⁻¹ per measure]: passive molar tracers, named by the keys of a NamedTuple, e.g. (; co2 = -1.2e-5) for CO₂ in mol CO₂ (one mol C per mol CO₂; not the biochemical enthalpy of assimilated carbon).

Sign: positive in the direction of the enclosing measure (element into air, upward across a face, into the named reservoir for a volume source). Host adapters own the conversions between conserved density tendencies and temperature or humidity.

Tracer rules:

  • Tracers are molar and passive. They carry no energy and no mass in these records. Leaving their mass out of the total-mass source is the trace approximation: with 12 µmol CO₂ m⁻² s⁻¹ against 4e-5 kg H₂O m⁻² s⁻¹ of transpiration, M_CO₂ × S_CO₂ is about 1.3 % of the water mass source (about 0.3 % net when the opposite O₂ flux is counted), and it dominates when transpiration is near zero (at night).
  • Water isotopologues (HDO, H₂¹⁸O) are subsets of water. Carried as tracers, they never enter total mass, which is water alone.
  • Bulk O₂ is not a trace constituent. An o2 key is a transfer ledger; it becomes a prognostic oxygen budget only if the host has a separate oxygen store contract.
  • A tracer that is not computed is not a key: absence is part of the type, never a stored zero. Passing a key with value zero asserts a zero transfer (for example no stem respiration); it does not mean "not computed". Records with different tracer names cannot be combined (ArgumentError).
  • Tracer order is part of the type: (; co2, o2) and (; o2, co2) are different record types and cannot be combined either.
  • The records assume a zero dry-air mass source: the total-mass source is the water source (see moist_air_tendencies).

All scalars, tracer values included, must be real and carry one floating-point type. Float32 with Float64 throws an ArgumentError, integers are rejected, and Float64 with a Float64-valued dual number promotes to the dual (with the ForwardDiff extension loaded).

Records support componentwise +, -, unary -, scalar * and /, zero, value equality == (-0.0 == 0.0, NaN != NaN; derivative components compared too, see CanopyExchange.scalar_equal), isequal and a consistent hash. In broadcasts a record is a scalar. Inference and zero allocations are tested up to 12 tracers; beyond 31 tracers Julia's tuple-inference limit makes the kernels type unstable.

Examples

julia> r = ExchangeRates(120.0, 2.0e-5, (; co2 = -1.0e-5));

julia> (r.energy, r.water, r.tracers.co2)
(120.0, 2.0e-5, -1.0e-5)

julia> keys((r + r).tracers)
(:co2,)

See also Tracers, Exchange, valid_exchange.

CanopyExchange.Tracers — Type
Tracers(names::Symbol...)
Tracers(:co2, :o2)(co2_value, o2_value) -> (; co2 = co2_value, o2 = o2_value)

Name tracer values positionally. Tracers(:co2, :o2) is a singleton callable, so it can be used inside broadcasts over GPU arrays and host fields, where a keyword argument or a NamedTuple type in the function position cannot. Values are in mol s⁻¹ per measure of the record that receives them (see ExchangeRates). Names must be unique.

Examples

julia> Tracers(:co2, :o2)(-1.2e-5, 1.3e-5)
(co2 = -1.2e-5, o2 = 1.3e-5)
CanopyExchange.valid_exchange — Function
valid_exchange(x) -> Bool

Whether every computed component of x is finite, including derivative components of dual numbers. Accepts ExchangeRates, any Exchange record and MoistAirTendencies. Absent tracers are not keys and are not checked. Hosts remain responsible for thermodynamic admissibility and retry policy.

Examples

julia> valid_exchange(leaf_flux(100.0, 2.0e-5, (; co2 = -1.0e-5)))
true

julia> valid_exchange(leaf_flux(NaN, 2.0e-5, (; co2 = -1.0e-5)))
false

Measures and measure-tagged records

CanopyExchange.Measure — Type
Measure

Supertype of the spatial measures that exchange rates are expressed per: LeafArea, StemArea, GroundArea, BulkVolume.

A new kind of element surface (fruit, flowers) is a new subtype; a geometry that provides CanopyExchange.area_density for it converts its fluxes to volume sources with volume_source, without changes to this package.

Several populations of the same element (sunlit and shaded leaves, cohorts) share LeafArea; they are not new subtypes. Their fluxes are per m² of their own leaf area, so the layer source is the sum over classes c of volume_source(F_c, LayerGeometry(Δz, LAD_c)). Adding the LeafFluxes of different populations without their area weights is wrong.

CanopyExchange.LeafArea — Type
LeafArea <: Measure

Per m² one-sided leaf area. A LeafFlux is positive from leaf into air.

CanopyExchange.StemArea — Type
StemArea <: Measure

Per m² one-sided woody (stem and branch) area. A StemFlux is positive from stem into air.

CanopyExchange.GroundArea — Type
GroundArea <: Measure

Per m² horizontal ground area. A FaceFlux is positive upward (+z).

CanopyExchange.BulkVolume — Type
BulkVolume <: Measure

Per m³ bulk canopy volume (air, leaves and stems together; ground footprint times layer thickness, with no porosity factor). A VolumeSource is positive into the named reservoir.

CanopyExchange.Exchange — Type
Exchange{M<:Measure}(rates::ExchangeRates)

ExchangeRates tagged with the spatial measure M they are expressed per. Arithmetic (+, -, unary -, scalar * and /, zero) exists only within one measure, so leaf, stem, face and volume quantities cannot be added or swapped by accident (MethodError). Equality and hashing include the measure.

Examples

julia> f = Exchange{LeafArea}(ExchangeRates(100.0, 3.0e-5, (; co2 = -1.2e-5)));

julia> f isa LeafFlux
true

julia> (2.0 * f).rates.energy
200.0
CanopyExchange.LeafFlux — Type
LeafFlux(rates::ExchangeRates)

Exchange{LeafArea}: rates per m² one-sided leaf area and second, positive from leaf into air. Usually built with sensible_water_flux or leaf_flux.

See also leaf_air_sources, StemFlux.

CanopyExchange.StemFlux — Type
StemFlux(rates::ExchangeRates)

Exchange{StemArea}: rates per m² one-sided stem area and second, positive from stem into air. Keeping it distinct from LeafFlux prevents swapping leaf and stem arguments in plant_air_sources or adding fluxes over unequal area denominators. Usually built with sensible_stem_flux or stem_flux.

CanopyExchange.FaceFlux — Type
FaceFlux(rates::ExchangeRates)

Exchange{GroundArea}: rates per m² horizontal ground area and second across a layer face, positive upward. Usually built with surface_static_energy_flux, face_flux or steady_top_flux.

CanopyExchange.VolumeSource — Type
VolumeSource(rates::ExchangeRates)

Exchange{BulkVolume}: sources per m³ bulk canopy volume and second, positive into the named reservoir (canopy air for air, the plant element for a donor ledger). Produced by volume_source, leaf_air_sources, plant_air_sources and layer_tendency.

CanopyExchange.leaf_flux — Function
leaf_flux(energy, water, tracers::NamedTuple = (;)) -> LeafFlux

Function form of LeafFlux(ExchangeRates(energy, water, tracers)) for broadcasts: energy [W m⁻² leaf] is the total transfer including the enthalpy of transported vapour, water [kg H₂O m⁻² leaf s⁻¹], tracers [mol m⁻² leaf s⁻¹]; positive from leaf into air. To build energy from sensible heat use sensible_water_flux.

CanopyExchange.stem_flux — Function
stem_flux(energy, water, tracers::NamedTuple = (;)) -> StemFlux

Function form of StemFlux(ExchangeRates(energy, water, tracers)) for broadcasts: per m² one-sided stem area and second, positive from stem into air. energy is the total transfer including the enthalpy of transported vapour; to build it from sensible heat use sensible_stem_flux or sensible_water_flux.

CanopyExchange.face_flux — Function
face_flux(energy, water, tracers::NamedTuple = (;)) -> FaceFlux

Function form of FaceFlux(ExchangeRates(energy, water, tracers)) for broadcasts: per m² ground area and second, positive upward. energy is the total transfer including the enthalpy of transported vapour; to build it from sensible heat use sensible_water_flux with GroundArea(), or surface_static_energy_flux for SurfaceFluxes.jl output.

Layer geometries

CanopyExchange.LayerGeometry — Type
LayerGeometry(thickness, leaf_area_density)

Finite-volume layer with finite positive thickness [m] and finite nonnegative one-sided leaf_area_density [m² leaf m⁻³ bulk canopy volume]. Bulk volume is the ground footprint times thickness, with no implicit porosity factor. Throws an ArgumentError for a nonpositive or nonfinite thickness, a negative or nonfinite density, or a nonfinite derivative component.

It implements the geometry interface (CanopyExchange.area_density) for leaves only, so a stem flux on it is a MethodError.

Examples

julia> g = LayerGeometry(1.5, 0.8);

julia> (CanopyExchange.thickness(g), CanopyExchange.area_density(g, LeafArea))
(1.5, 0.8)
CanopyExchange.PlantLayerGeometry — Type
PlantLayerGeometry(thickness, leaf_area_density, stem_area_density)
PlantLayerGeometry(thickness, leaf_area_density)

As LayerGeometry, with finite nonnegative one-sided stem_area_density [m² stem m⁻³ bulk canopy volume] (PAI = LAI + SAI as in ClimaLand). The two-argument form sets the stem area density to zero(leaf_area_density).

Examples

julia> g = PlantLayerGeometry(2.0, 1.2, 0.3);

julia> (CanopyExchange.area_density(g, StemArea), plant_area_density(g))
(0.3, 1.5)
CanopyExchange.layer_geometry — Function
layer_geometry(thickness, leaf_area_density) -> LayerGeometry
layer_geometry(thickness, leaf_area_density, stem_area_density) -> PlantLayerGeometry

Function form of the geometry constructors for broadcasts over host fields, where a type in the function position is rejected. Units and checks as in LayerGeometry and PlantLayerGeometry.

CanopyExchange.area_density — Function
CanopyExchange.area_density(geometry, ::Type{M}) where {M<:Measure}

One-sided area density [m² element area m⁻³ bulk canopy volume] of the element class with measure M in geometry.

Geometry interface. A layer geometry is any type G that provides

  • CanopyExchange.thickness(g::G) [m] (or a field thickness), and
  • CanopyExchange.area_density(g::G, ::Type{M}) for every element class M it holds.

Both are public, not exported: extend them with qualified names. A flux of a class the geometry does not hold is a MethodError in volume_source. Base.eltype is not required. To use a geometry as a scalar in broadcasts (volume_source.(fluxes, g)), define Base.Broadcast.broadcastable(g::G) = Ref(g) or pass Ref(g). The package cannot validate an external geometry: it must itself guarantee a finite positive thickness and finite nonnegative area densities, of the same floating-point type as the fluxes (the kernels check the type, not the values).

Examples

julia> struct Orchard{FT}; thickness::FT; leaf_area_density::FT; end

julia> CanopyExchange.area_density(g::Orchard, ::Type{LeafArea}) = g.leaf_area_density;

julia> volume_source(leaf_flux(100.0, 2.0e-5), Orchard(2.0, 0.5)).rates.energy
50.0
CanopyExchange.thickness — Function
CanopyExchange.thickness(geometry)

Layer thickness [m] of a layer geometry; part of the geometry interface (see CanopyExchange.area_density). The default reads a thickness field.

CanopyExchange.plant_area_density — Function
plant_area_density(geometry)

Total one-sided plant area density [m² m⁻³]: LAD for a LayerGeometry, LAD + SAD for a PlantLayerGeometry (PAI_k / Δz_k).

Examples

julia> (plant_area_density(LayerGeometry(1.5, 0.8)), plant_area_density(PlantLayerGeometry(1.5, 0.8, 0.2)))
(0.8, 1.0)
