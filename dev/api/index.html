API Reference

This section documents all exported and public names of CanopyExchange, grouped by physical process.

CanopyExchange — Module
CanopyExchange

Measure-safe, conservative scalar exchange contracts between layered plant canopies and atmospheric or land host models (ClimaLand, SurfaceFluxes, ClimaAtmos and standalone finite-volume columns), with no runtime dependencies.

Rates of energy (including transported vapour enthalpy), water and an open set of passive molar tracers (ExchangeRates) are tagged with the measure they are expressed per (Exchange: leaf area, stem area, ground area, bulk volume). The package converts element fluxes to paired bulk-volume sources, evaluates conservative finite-volume flux divergences, bridges diagnostic steady-air profiles and prognostic columns, and maps bulk sources to gas-volume moist-air tendencies. It works with Float32 and Float64, inside broadcasts over GPU arrays and ClimaCore fields, and with ForwardDiff dual numbers (through a package extension). It owns no state, grid, turbulence closure, equation of state or time integrator.

Source files, one per process: precision.jl (scalar hooks and the precision policy), records.jl (equality, hashing and broadcasting of every record), rates.jl, measures.jl, geometry.jl, area_to_volume.jl, flux_divergence.jl, water_energy.jl (vapour enthalpy, surface static energy, energy datum) and moist_air.jl.

Conventions

  • Exported and public names: names shown unqualified are exported by using CanopyExchange. The interfaces that other code extends are public on Julia 1.11+ and not exported: the geometry interface (CanopyExchange.thickness, CanopyExchange.area_density) and the scalar hooks (CanopyExchange.primal_type, CanopyExchange.primal, CanopyExchange.all_finite, CanopyExchange.exact_zero, CanopyExchange.scalar_equal).
  • Precision: every scalar that meets in a record or kernel carries one floating-point type. Float32 with Float64, integers, rationals and irrationals throw an ArgumentError; Float64 with a Float64-valued dual promotes.
  • Kernels: positional arguments only, no keyword arguments, static error messages, zero heap allocations (tested with 2 and 12 tracers; beyond 31 tracers Julia's tuple inference limit breaks this); they broadcast over CuArray and ClimaCore.Fields.Field. A measure instance (StemArea()) is a broadcast scalar. Construction inside such broadcasts uses the function forms (leaf_flux, face_flux, layer_geometry, Tracers(:co2)), not type constructors.
