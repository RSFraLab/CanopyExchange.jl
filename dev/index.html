CanopyExchange.jl

Zero-dependency, measure-safe scalar exchange contracts for layered plant canopies and atmospheric or land host models.

CanopyExchange owns spatial measure wrappers (LeafFlux, StemFlux, FaceFlux, VolumeSource, MoistAirTendencies) and conservative transfer arithmetic connecting leaf/stem physiology to canopy-air and atmospheric column budgets. It carries zero runtime dependencies, runs allocation-free across Float32, Float64, CuArray, and ClimaCore.Fields.Field broadcasting, and propagates ForwardDiff.Dual derivatives cleanly.

Spatial Measures & Sign Conventions

TypeSpatial DenominatorPositive DirectionPrimary Constructors & Producers
LeafFlux$\mathrm{m^2}$ one-sided leaf area (LAD)Leaf $\to$ airLeafFlux, sensible_water_flux
StemFlux$\mathrm{m^2}$ one-sided stem area (SAD)Stem $\to$ airStemFlux, sensible_stem_flux
FaceFlux$\mathrm{m^2}$ horizontal ground areaUpward ($+z$)FaceFlux, surface_static_energy_flux, steady_top_flux
VolumeSource$\mathrm{m^3}$ bulk canopy volumeInto named ledgerleaf_air_sources, plant_air_sources, layer_tendency
MoistAirTendencies$\mathrm{m^3}$ gas volume ($\varepsilon_{\mathrm{gas}} \in (0, 1]$)Into canopy airmoist_air_tendencies

Distinct concrete types forbid accidental cross-measure addition (LeafFlux + StemFlux or LeafFlux + FaceFlux throws MethodError) and prevent swapping leaf and stem arguments in plant_air_sources.

Quickstart

julia> using CanopyExchange

julia> geom = PlantLayerGeometry(2.0, 1.2, 0.25); # thickness [m], LAD [m² m⁻³], SAD [m² m⁻³]

julia> lf = sensible_water_flux(95.0, 4.0e-5, -1.4e-5, 2.547e6); # H, E, CO₂, h_v(T_leaf)

julia> sf = sensible_stem_flux(20.0); # dry woody sensible heat [W m⁻² stem]

julia> srcs = plant_air_sources(lf, sf, geom); # conservative (; air, leaf, stem) ledgers

julia> srcs.air + (srcs.leaf + srcs.stem) == zero(srcs.air)
true

julia> soil = surface_static_energy_flux(45.0, 90.0, 3.6e-5, 2.0e-6); # SurfaceFluxes boundary

julia> top = steady_top_flux(soil, srcs.air, geom); # zero-storage diagnostic top FaceFlux

julia> tend = layer_tendency(soil, top, srcs.air, geom); # (bottom - top)/dz + air

julia> moist = moist_air_tendencies(tend, 0.96); # per m³ gas volume (ε_gas = 0.96)

julia> abs(moist.rho_energy) <= 1.0e-12
true
