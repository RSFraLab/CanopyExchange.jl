CanopyExchange.jl

Measure-safe, conservative scalar exchange contracts for layered plant canopies and atmospheric or land host models, with no runtime dependencies.

CanopyExchange tags rates of energy, water and an open set of passive molar tracers (ExchangeRates) with the measure they are expressed per (Exchange), and provides the conservative arithmetic that connects leaf and stem physiology to canopy-air and atmospheric column budgets. Kernels are allocation-free in Float32 and Float64 (tested with up to 12 tracers), broadcast over CuArray and ClimaCore.Fields.Field, and propagate ForwardDiff.Dual derivatives (through a package extension).

Spatial measures and sign conventions

RecordMeasurePositive directionConstructors and producers
LeafFluxm² one-sided leaf area (LAD)leaf → airsensible_water_flux, leaf_flux
StemFluxm² one-sided stem area (SAD)stem → airsensible_stem_flux, stem_flux
FaceFluxm² horizontal ground areaupward (+z)surface_static_energy_flux, face_flux, steady_top_flux
VolumeSourcem³ bulk canopy volumeinto the named ledgervolume_source, leaf_air_sources, plant_air_sources, layer_tendency
MoistAirTendenciesm³ gas volume (ε_gas ∈ (0, 1])into canopy airmoist_air_tendencies

Records of different measures cannot be added or swapped (MethodError); records with different tracer sets or floating-point precisions cannot be combined (ArgumentError).

Quickstart

julia> using CanopyExchange

julia> geom = PlantLayerGeometry(2.0, 1.2, 0.25); # thickness [m], LAD [m² m⁻³], SAD [m² m⁻³]

julia> T = Tracers(:co2); # passive molar tracers carried by every record

julia> lf = sensible_water_flux(95.0, 4.0e-5, 2.547e6, T(-1.4e-5)); # H, E, h_v(T_leaf), CO₂

julia> sf = sensible_stem_flux(20.0, T(0.0)); # dry woody sensible heat [W m⁻² stem]

julia> srcs = plant_air_sources(lf, sf, geom); # conservative (; air, leaf, stem) ledgers

julia> srcs.air + (srcs.leaf + srcs.stem) == zero(srcs.air)
true

julia> soil = surface_static_energy_flux(45.0, 90.0, 3.6e-5, T(2.0e-6)); # SurfaceFluxes boundary

julia> top = steady_top_flux(soil, srcs.air, geom); # zero-storage diagnostic top FaceFlux

julia> tend = layer_tendency(soil, top, srcs.air, geom); # (bottom - top)/dz + air

julia> moist = moist_air_tendencies(tend, 0.96); # per m³ gas volume (ε_gas = 0.96)

julia> abs(moist.rho_energy) <= 1.0e-12
true
