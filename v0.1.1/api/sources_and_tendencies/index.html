Area Sources & Finite-Volume Divergence

Source and divergence kernels map one-sided leaf (LAD) and woody/stem (SAD) fluxes into paired donor-conserving bulk-volume sources and evaluate finite-volume vertical flux divergences across shared horizontal interfaces.

Scalar Area-to-Volume Primitives

CanopyExchange.area_source — Function
area_source(rate::Real, area_density::Real)

Convert a scalar transfer per unit one-sided plant surface area and second to a bulk canopy volume source by multiplying by area_density once.

When exact_zero_scalar(area_density) holds (both primal and derivative partials are zero), return exact zero(FT) without multiplying rate, guarding empty layers against nonfinite dummy element rates on CPU, GPU, and AD paths. When the primal of area_density is zero with a nonzero AD tangent (Dual(0.0, 1.0)), evaluate rate * area_density directly (requiring finite rate) so the right directional derivative ∂(rate * a)/∂a = rate is preserved.

Examples

julia> area_source(150.0, 0.8)
120.0

julia> area_source(NaN, 0.0)
0.0
CanopyExchange.leaf_area_source — Function
leaf_area_source(leaf_rate::Real, geometry::AbstractLayerGeometry)

Convert a scalar transfer per m² one-sided leaf area and second to a bulk canopy volume source [m⁻³ s⁻¹] by multiplying geometry.leaf_area_density once.

Positive values denote transfer into canopy air; negate the result for the paired leaf ledger. For zero leaf-area density (with zero AD partials), return exact zero even when leaf_rate is nonfinite.

Examples

julia> leaf_area_source(2.0e-5, LayerGeometry(1.5, 0.5))
1.0e-5
CanopyExchange.stem_area_source — Function
stem_area_source(stem_rate::Real, geometry::PlantLayerGeometry)

Convert a scalar transfer per m² one-sided stem area and second to a bulk canopy volume source [m⁻³ s⁻¹] by multiplying geometry.stem_area_density once.

For zero stem-area density (with zero AD partials), return exact zero even when stem_rate is nonfinite.

Examples

julia> stem_area_source(40.0, PlantLayerGeometry(2.0, 1.2, 0.25))
10.0
CanopyExchange.plant_area_density — Function
plant_area_density(geometry::AbstractLayerGeometry)

Return total one-sided plant area density (LAD for LayerGeometry, or LAD + SAD for PlantLayerGeometry) in m² plant area per m³ bulk canopy.

Examples

julia> (plant_area_density(LayerGeometry(1.5, 0.8)), plant_area_density(PlantLayerGeometry(1.5, 0.8, 0.2)))
(0.8, 1.0)

See also LayerGeometry, PlantLayerGeometry, plant_air_sources.

Enthalpy-Coupled Element Flux Constructors

CanopyExchange.sensible_water_flux — Function
sensible_water_flux(sensible_heat, water_flux, carbon_flux, oxygen, vapor_enthalpy)
sensible_water_flux(sensible_heat, water_flux, carbon_flux, vapor_enthalpy)

Construct a LeafFlux from sensible heat [W m⁻² leaf], signed water flux [kg H₂O m⁻² leaf s⁻¹], signed CO₂ flux [mol C m⁻² leaf s⁻¹], optional oxygen, and transported water-vapor specific enthalpy vapor_enthalpy [J kg⁻¹].

Total leaf-to-air energy transfer is sensible_heat + water_flux * vapor_enthalpy. Positive fluxes enter canopy air (photosynthetic carbon uptake is negative carbon_flux; condensation is negative water_flux). Do not add a separate latent-heat source when coupling this record to a conserved air energy budget.

Examples

julia> f = sensible_water_flux(80.0, 4.0e-5, -1.2e-5, 2.5e6);

julia> f.rates.energy
180.0
CanopyExchange.sensible_stem_flux — Function
sensible_stem_flux(sensible_heat, oxygen=NoOxygen(FT))
sensible_stem_flux(sensible_heat, water_flux, carbon_flux, oxygen, vapor_enthalpy)
sensible_stem_flux(sensible_heat, water_flux, carbon_flux, vapor_enthalpy)

Construct a StemFlux per m² one-sided stem area and second.

The 1- and 2-argument forms construct a dry, non-assimilating woody sensible-heat flux (water = 0, carbon = 0). When nonzero stem evaporation or respiration is supplied via the 4- or 5-argument form, vapor_enthalpy [J kg⁻¹] is mandatory so transported water enthalpy water_flux * vapor_enthalpy is never silently omitted.

Examples

julia> s = sensible_stem_flux(35.0)
StemFlux{Float64, NoOxygen{Float64}}(ExchangeRates{Float64, NoOxygen{Float64}}(35.0, 0.0, 0.0, NoOxygen{Float64}()))

Paired Leaf, Stem & Canopy-Air Ledgers

CanopyExchange.leaf_air_sources — Function
leaf_air_sources(flux::LeafFlux, geometry::AbstractLayerGeometry) -> (air, leaf)

Return paired (air, leaf) VolumeSource ledgers by multiplying flux by LAD once.

leaf equals -air with IEEE sign-bit negation, representing an equal-and-opposite exchange ledger rather than independent leaf gas storage or leaf temperature rate of change. When exact_zero_scalar(geometry.leaf_area_density) holds, return exact finite zeros even if flux holds nonfinite dummy values.

Examples

julia> f = LeafFlux(ExchangeRates(100.0, 2.0e-5, -1.0e-5));

julia> p = leaf_air_sources(f, LayerGeometry(2.0, 0.5));

julia> (p.air.rates.energy, p.leaf.rates.energy)
(50.0, -50.0)
CanopyExchange.plant_air_sources — Function
plant_air_sources(leaf_flux::LeafFlux, stem_flux::StemFlux, geometry::PlantLayerGeometry)

Return conservative (air, leaf, stem) VolumeSource ledgers for a leaf-and-stem layer.

leaf_flux scales by geometry.leaf_area_density, stem_flux scales by geometry.stem_area_density with independent zero-density guards, air equals leaf_air + stem_air, and leaf and stem hold the opposite donor ledgers so air + leaf + stem == zero(air).

Examples

julia> lf = LeafFlux(ExchangeRates(100.0, 2.0e-5, -1.0e-5));

julia> sf = sensible_stem_flux(40.0);

julia> s = plant_air_sources(lf, sf, PlantLayerGeometry(2.0, 1.0, 0.25));

julia> (s.air.rates.energy, s.leaf.rates.energy, s.stem.rates.energy)
(110.0, -100.0, -10.0)

Finite-Volume Vertical Divergence

CanopyExchange.conserved_tendency — Function
conserved_tendency(bottom_rate, top_rate, source, geometry::AbstractLayerGeometry)

Compute scalar finite-volume conserved tendency (bottom_rate - top_rate) / thickness + source.

bottom_rate and top_rate are upward-positive fluxes per common horizontal ground area, and source is per bulk canopy volume. Summing thickness-weighted tendencies across stacked layers cancels interior face fluxes identically.

Examples

julia> conserved_tendency(15.0, 12.0, 4.0, LayerGeometry(1.5, 0.8))
6.0
CanopyExchange.layer_tendency — Function
layer_tendency(bottom::FaceFlux, top::FaceFlux, source::VolumeSource, geometry::AbstractLayerGeometry)

Compute conservative bulk-volume VolumeSource tendency (bottom - top) / thickness + source.

All face fluxes are upward-positive across shared horizontal ground area, and all inputs must share compatible continuous scalar precision and matching oxygen mode. Summing thickness * tendency across adjacent layers telescopes interior faces.

Examples

julia> b = FaceFlux(ExchangeRates(30.0, 0.0, 0.0));

julia> t = FaceFlux(ExchangeRates(24.0, 0.0, 0.0));

julia> s = VolumeSource(ExchangeRates(10.0, 0.0, 0.0));

julia> layer_tendency(b, t, s, LayerGeometry(2.0, 0.5)).rates.energy
13.0
