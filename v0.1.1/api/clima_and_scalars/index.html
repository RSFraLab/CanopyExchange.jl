CliMA Contracts & Continuous-Scalar Traits

Boundary, column-accumulation, and porous-medium tendency contracts bridge CanopyExchange with SurfaceFluxes.jl, Thermodynamics.jl, ClimaLand.jl, ClimaAtmos.jl, and ClimaCore.jl without introducing runtime package dependencies. Semi-public continuous-scalar trait functions (public on Julia 1.11+) govern precision safety, ForwardDiff.Dual promotion, and structural leaf-float predicates.

Boundary Static-Energy & Datum Shifts

CanopyExchange.surface_static_energy_flux — Function
surface_static_energy_flux(shf, lhf, evaporation, carbon_flux=zero(FT), oxygen=NoOxygen(FT))

Construct an upward-positive FaceFlux from SurfaceFluxes.jl static-energy outputs.

In CliMA's SurfaceFluxes.jl convention (SHF = -ρ_sfc g_h ΔDSE + VSE_sfc E and LHF = LH_v0 E with LH_v0 + VSE_sfc == Thermodynamics.enthalpy_vapor(T_sfc) + Φ_sfc), shf + lhf equals the total moist static enthalpy plus surface-geopotential flux -ρ_sfc g_h ΔDSE + E * (h_v(T_sfc) + Φ_sfc) relative to Thermodynamics.jl's zero-energy datum, where evaporation [kg H₂O m⁻² s⁻¹] is the kinematic water mass flux. Conventional eddy-covariance c_p ΔT + L_v(T_air) E does not satisfy this static-energy datum without an explicit shift via shift_water_energy_datum.

Examples

julia> f = surface_static_energy_flux(60.0, 140.0, 5.6e-5, -1.5e-5);

julia> (f.rates.energy, f.rates.water, f.rates.carbon)
(200.0, 5.6e-5, -1.5e-5)

See also shift_water_energy_datum, sensible_water_flux, FaceFlux.

CanopyExchange.shift_water_energy_datum — Function
shift_water_energy_datum(stream, delta_specific_energy::Real)

Shift the energy component of stream by delta_specific_energy * water [J kg⁻¹ H₂O].

Apply reference-enthalpy offsets (h_v,target - h_v,source) or geopotential offsets (Φ_target - Φ_source) directly to individual ExchangeRates, LeafFlux, StemFlux, FaceFlux, or VolumeSource streams before layer_tendency so interior face fluxes remain identical on shared interfaces and telescope conservatively across multi-layer columns. Purely positional arguments support @. broadcasting over ClimaCore.Fields.Field and CuArray.

Examples

julia> f = FaceFlux(ExchangeRates(100.0, 2.0e-4, 0.0));

julia> shift_water_energy_datum(f, 5.0e4).rates.energy
110.0

Diagnostic Steady-Air Flux Profiles

CanopyExchange.layer_flux_increment — Function
layer_flux_increment(source::VolumeSource, geometry::AbstractLayerGeometry) -> FaceFlux

Integrate bulk-volume source across geometry.thickness to a FaceFlux increment.

Examples

julia> s = VolumeSource(ExchangeRates(40.0, 1.0e-5, -0.5e-5));

julia> layer_flux_increment(s, LayerGeometry(2.5, 0.8)).rates.energy
100.0
CanopyExchange.steady_top_flux — Function
steady_top_flux(bottom::FaceFlux, source::VolumeSource, geometry::AbstractLayerGeometry) -> FaceFlux

Return the upward FaceFlux at the layer top under zero air-storage tendency.

Satisfies layer_tendency(bottom, steady_top_flux(bottom, source, geometry), source, geometry) ≈ zero(source), bridging diagnostic zero-storage canopy models (ClimaLand big-leaf / diagnostic multi-layer turbulence) with prognostic finite-volume columns.

Examples

julia> b = FaceFlux(ExchangeRates(20.0, 0.0, 0.0));

julia> s = VolumeSource(ExchangeRates(15.0, 0.0, 0.0));

julia> g = LayerGeometry(2.0, 0.6);

julia> t = steady_top_flux(b, s, g);

julia> (t.rates.energy, layer_tendency(b, t, s, g).rates.energy)
(50.0, 0.0)
CanopyExchange.accumulate_steady_fluxes! — Function
accumulate_steady_fluxes!(faces, bottom, sources, geometries)

Overwrite faces (N + 1 elements) in place from bottom upward across N layers and return faces.

sources and geometries must share identical axes(sources, 1) == axes(geometries, 1) (supporting OffsetArray and @view), and faces must satisfy length(faces) == length(sources) + 1, throwing DimensionMismatch otherwise. At completion, faces[end] holds the emergent canopy-top FaceFlux equal to bottom + sum_k thickness_k * sources_k.

Examples

julia> b = FaceFlux(ExchangeRates(10.0, 0.0, 0.0));

julia> s = [VolumeSource(ExchangeRates(6.0, 0.0, 0.0))];

julia> g = [LayerGeometry(2.0, 0.5)];

julia> faces = Vector{typeof(b)}(undef, 2);

julia> accumulate_steady_fluxes!(faces, b, s, g);

julia> [f.rates.energy for f in faces]
2-element Vector{Float64}:
 10.0
 22.0

See also accumulate_steady_fluxes, steady_top_flux, layer_flux_increment.

CanopyExchange.accumulate_steady_fluxes — Function
accumulate_steady_fluxes(bottom::FaceFlux, sources, geometries) -> Vector{<:FaceFlux}

Allocate and return a 1-based N + 1 steady-state FaceFlux profile from bottom to canopy top.

Pass a preallocated staggered vector (including OffsetVector) to accumulate_steady_fluxes! when custom face index axes are required.

Examples

julia> b = FaceFlux(ExchangeRates(10.0, 0.0, 0.0));

julia> s = [VolumeSource(ExchangeRates(5.0, 0.0, 0.0)), VolumeSource(ExchangeRates(8.0, 0.0, 0.0))];

julia> g = [LayerGeometry(2.0, 0.5), LayerGeometry(1.5, 0.4)];

julia> faces = accumulate_steady_fluxes(b, s, g);

julia> [f.rates.energy for f in faces]
3-element Vector{Float64}:
 10.0
 20.0
 32.0

See also accumulate_steady_fluxes!, steady_top_flux.

Conserved Gas-Volume Moist-Air Tendencies

CanopyExchange.moist_air_tendencies — Function
moist_air_tendencies(tendency::VolumeSource, gas_fraction::Real=one(eltype(tendency))) -> MoistAirTendencies

Convert a bulk-volume VolumeSource into gas-volume MoistAirTendencies by dividing by gas_fraction.

Contracts:

  • gas_fraction is the time-invariant air porosity ε_gas ∈ (0, 1] (∂_t ε_gas = 0); throw ArgumentError if gas_fraction ≤ 0, gas_fraction > 1, or nonfinite.
  • Dry-air mass is conserved (S_ρd = 0), so rho_total == rho_water == water / gas_fraction.
  • Fieldwise division / gas_fraction preserves exact identity at gas_fraction == 1 and zero-ULP molar O₂ / CO₂ stoichiometry.
  • Apply any reference-enthalpy or geopotential shift to individual streams via shift_water_energy_datum prior to layer_tendency.
  • Purely positional arguments support @. broadcasting over ClimaCore.Fields.Field and CuArray.

Examples

julia> v = VolumeSource(ExchangeRates(180.0, 3.6e-5, -1.8e-5));

julia> m = moist_air_tendencies(v, 0.9);

julia> (m.rho_total, m.rho_water, m.rho_energy, m.carbon)
(4.0e-5, 4.0e-5, 200.0, -2.0e-5)

Continuous-Scalar & Oxygen Traits (public)

CanopyExchange.primal_float_type — Function
primal_float_type(::Type{T}) -> Type

Return the underlying leaf floating-point type of continuous scalar type T.

For T <: AbstractFloat, return T directly. For concrete composite Real types whose first field stores the primal value (such as ForwardDiff.Dual), recurse until reaching the underlying AbstractFloat.

Examples

julia> CanopyExchange.primal_float_type(Float32)
Float32

See also CanopyExchange.primal_scalar, CanopyExchange.is_continuous_scalar.

CanopyExchange.primal_scalar — Function
primal_scalar(x::Real) -> AbstractFloat

Extract the underlying primal floating-point value from continuous scalar x.

Examples

julia> CanopyExchange.primal_scalar(2.5f0)
2.5f0

See also CanopyExchange.primal_float_type, CanopyExchange.finite_scalar.

CanopyExchange.is_continuous_scalar — Function
is_continuous_scalar(::Type{T}) -> Bool

Return true if T is a concrete continuous Real scalar backed by an AbstractFloat.

Reject abstract types (Real, AbstractFloat), discrete scalar types (Bool, Integer, Rational, AbstractIrrational), and composite duals built over discrete scalar types.

Examples

julia> (CanopyExchange.is_continuous_scalar(Float64), CanopyExchange.is_continuous_scalar(Int))
(true, false)

See also CanopyExchange.compatible_scalar, CanopyExchange.primal_float_type.

CanopyExchange.compatible_scalar — Function
compatible_scalar(::Type{A}, ::Type{B}) -> Bool

Return true if A and B are continuous scalars sharing the identical primal float type.

This permits automatic differentiation promotion (Float64 with ForwardDiff.Dual{Tag,Float64,N}) while rejecting mixed floating-point precisions (Float32 with Float64) and discrete scalar types.

Examples

julia> (CanopyExchange.compatible_scalar(Float64, Float64), CanopyExchange.compatible_scalar(Float32, Float64))
(true, false)

See also CanopyExchange.is_continuous_scalar, CanopyExchange.compatible_oxygen.

CanopyExchange.compatible_oxygen — Function
compatible_oxygen(::Type{O1}, ::Type{O2}) -> Bool

Return true if O1 and O2 represent the same oxygen mode over compatible continuous scalars.

Both types must be NoOxygen or both must be OxygenTransfer, and their scalar parameters must satisfy CanopyExchange.compatible_scalar.

Examples

julia> CanopyExchange.compatible_oxygen(NoOxygen{Float64}, NoOxygen{Float64})
true

julia> CanopyExchange.compatible_oxygen(NoOxygen{Float64}, OxygenTransfer{Float64})
false

See also CanopyExchange.compatible_scalar, OxygenContent.

CanopyExchange.finite_scalar — Function
finite_scalar(x::Real) -> Bool

Return true if every leaf floating-point component of x (primal and partials) is finite.

Unlike Base.isfinite on ForwardDiff.Dual, which inspects only the primal value, finite_scalar unrolls all composite struct and tuple fields at compile time in zero allocations and rejects NaN or Inf in derivative partials.

Examples

julia> (CanopyExchange.finite_scalar(1.5), CanopyExchange.finite_scalar(NaN))
(true, false)

See also CanopyExchange.exact_zero_scalar, valid_exchange.

CanopyExchange.exact_zero_scalar — Function
exact_zero_scalar(x::Real) -> Bool

Return true if every leaf floating-point component of x (primal and partials) is zero.

Evaluate iszero structurally across all leaf AbstractFloat components in zero allocations, handling IEEE ±0.0, BigFloat(0), and nested ForwardDiff.Dual numbers without pointer-identity comparisons (===).

Examples

julia> (CanopyExchange.exact_zero_scalar(-0.0), CanopyExchange.exact_zero_scalar(1.0e-12))
(true, false)

See also CanopyExchange.finite_scalar, area_source.
