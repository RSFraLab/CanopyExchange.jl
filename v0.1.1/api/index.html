API Reference

This section documents all exported and public types and functions in CanopyExchange, grouped by physical domain rather than alphabetical order.

CanopyExchange — Module
CanopyExchange

Provide zero-dependency, measure-safe scalar exchange contracts for layered plant canopies and atmospheric / land host models (including ClimaLand, SurfaceFluxes, and ClimaAtmos).

CanopyExchange converts one-sided leaf (LAD) and stem (SAD) fluxes into paired bulk-volume sources, evaluates conservative finite-volume vertical flux divergences, bridges diagnostic steady-air flux profiles with prognostic air columns, and maps bulk sources to conserved gas-volume moist-air tendencies across Float32, Float64, GPU arrays (CuArray), ClimaCore.Fields.Field broadcasting, and ForwardDiff automatic differentiation. It owns no state, grid, turbulence closure, equation of state, or time integrator.

Conventions

  • Exported vs. public bindings: Symbols shown unqualified (LeafFlux, plant_air_sources, moist_air_tendencies) are exported by using CanopyExchange. Continuous-scalar trait and leaf-float predicate functions declared public on Julia 1.11+ (CanopyExchange.primal_float_type, CanopyExchange.finite_scalar, CanopyExchange.exact_zero_scalar, etc.) are part of the supported API when qualified with CanopyExchange. or explicitly imported.
  • Precision, device & AD contract: All structs and functions preserve caller floating-point precision (Float32, Float64, BigFloat), allocate zero heap memory on scalar paths, broadcast via @. over CuArray and ClimaCore.Fields.Field, and propagate ForwardDiff.Dual tangents while rejecting mixed Float32/Float64 precisions and discrete integer/rational types.
